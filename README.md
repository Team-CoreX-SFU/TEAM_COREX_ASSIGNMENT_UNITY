## Getting Started

### Prerequisites
- Unity Editor 2022.3.35f1
- Git for version control


### Player Guide

1. go near to metal plate. press `enter` to cut. (no hand movement needed)
2. get batteries. ( `shift` or `space` + `g` ) or ( `t` or `y` + `g` ) to grab (hand movement needed).
3. get flashlight (hand movement needed)
4. for radio, go near and press `e`. (no hand movement needed)
5. toggle flashlight is `b`. (no need `shift`)
6. screwdriver, the same as batteries grabbing.
7. power supply switch, press `e` to open the cover. wait 3 or more sec for animation. then, press `e` again to turn off switch and remove fuse (no hand movement needed)
8. keypad, touch with hand. don't need to press anything.
